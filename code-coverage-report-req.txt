Requirements

Goal
- Analyze `Cobertura.xml` and generate one combined Markdown coverage report.

Metrics (must use these exact definitions)
- Metric A: number of files with coverage exactly `0%`.
- Metric B: number of files with coverage `> 0%` and `< 85%`.
- Metric C: number of files with coverage `>= 85%`.

Grouping
- Group files by top-level folder under `src`, i.e. `/src/<subfolder>`.
- Example: `src/adu-shell/src/aptget_tasks.cpp` belongs to `/src/adu-shell`.
- Use the first `src/` path root when normalizing file paths.

Output file
- `coverage-report.md` (single file)
	- Includes a Summary section with:
		- Overall line coverage percentage (and covered/valid line counts).
		- Overall branch coverage percentage (and covered/valid branch counts).
		- Overall function coverage percentage (and covered/total function counts).
		- Overall totals for Metric A, Metric B, and Metric C.
		- Table by `/src/<subfolder>` with:
			- Total files
			- Files at `0%`
			- Files with `>0% && <85%`
			- Files with `>=85%`
			- Hit/Total lines per subfolder
			- Subfolder coverage percentage
	- Includes a Details section in the same file:
		- One subsection per `/src/<subfolder>`
		- For each subsection:
			- Total files
			- Files at `0%`
			- Files with `>0% && <85%`
			- Files with `>=85%`
			- Hit/Total lines per subfolder
			- Subfolder coverage percentage
			- Per-file table with file path, hit/total lines, exact coverage %, and flags.

Implementation notes
- Parse coverage from each `<class filename="..." line-rate="...">` entry.
- Deduplicate by normalized filename (if duplicates exist, keep the highest coverage).
- Include only files under `src/` in folder distribution sections.
- Calculate subfolder coverage percentage as:
	- `(sum of covered lines across files in subfolder) / (sum of valid lines across files in subfolder) * 100`
- Hit/Total lines definitions:
	- `hit lines` = number of lines with `hits > 0`
	- `total lines` = number of valid instrumented lines
- Function coverage is based on `<method>` entries:
	- `covered functions / total functions * 100`

Expected behavior when I ask: "do what's asked in req.txt"
- Regenerate `coverage-report.md` from the current `Cobertura.xml`.
- Overwrite the report file with fresh results.
